The Site Itself

After I got things setup how I like them, I needed to start coding the site I had codded a lot of sites in the past for fun, but those were local and using vite, For this project I had to use a tool called Caddy. Caddy is a really neat peice of software that acts as a reverse proxy. Basicly, When you search up liamis.dev, your browsers goal is to get the files for the site and talk to the server hosting it, but all your sever has is a name! Your browser usses your domain name, to then talk to DNS query, All this is, is your browser talking to a server who has a list of domain names, and IP addresses for servers You give it a name, and it gives you a location, then your browser talks to my server, they have a lovley conversation that goes like this "I want to go to liamis.dev", "Yoooooo I gotchu dw", "Wait, how do I know if you are safe!??!?! ID PLEASE", "Dw I got this certificate, its all fine, and here is the site you wanted", 5 seconds later "My person clicked on this link to your blogs site, whats the data for that" "here ya go, blogs you said?" This conversation goes on for quite some time about what the browser needs, and the server giving it. Few things to note here, 1 The job of caddy is to listen to incoming trafic from people, and then if they ask for liamis.dev, Caddy gives them the data for the site That is what a reverse proxy does! Next the certificate is called a TLS certificate, It just says that I own my server, and domain. It also verifies that I will encrypt stuff for security! Caddy gives me that certificate automatically by getting it from Let's Encrypt. With all that done, Whats a domain name and how do you get one? All a domain name is something like amazon.com, or liamis.dev, we have them since people when they want to go to their site do not want to have to type in 127.00.10 since that is hard to remember! So we have Domains. To get a domain, you buy it from someone, I got mine from porkbun for about 10$/year (not joking, they are CHEAP!), then I told porkbun, hey when someone goes to this DNS, send them to my server It is that simple!

This whole process of DNS and Servers took me about 2 days and a couple hours of work, the first time that I did any of this, it took me about 5 hours in total for experience The next thing that I had to do was setup git, git is really useful for keeping track of your code, and for servers! On my laptop my coding enviroment has my tools, my plugins, My colour themes everything the way I like, and so I like to code on it instead of my servers. This creates a problem though, how do I get my code onto that server? To do that I create a repo(Repository) on github, code on my laptop, push code to github then pull it down on my server.
