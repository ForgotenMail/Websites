Section Heading

Use <h2> tags for section headings within your article. Inline <code> snippets look like this: const answer = 42;. They're great for mentioning function names, variable names, or short terminal commands like git push origin main.

You can have multiple paragraphs per section. Keep them focused — each paragraph should cover a single idea. The line height and spacing are already set for comfortable reading.

Code Blocks

For longer code snippets use a <pre> block with a <code> tag inside: 

package main

import "fmt"

func main() {
    fmt.Println("Hello, world!")
}

The code block has a dark background with a subtle border. Code inside <pre> uses the site's monospace font and has comfortable line height.

Lists (Manual)

There's no automatic list styling, but you can create lists manually with text:

— First item in the list
— Second item, which might be longer
— Third item to wrap things up

Or numbered with 1., 2., etc.
1. First step
2. Second step
3. Third step
